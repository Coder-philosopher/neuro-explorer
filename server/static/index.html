WHAT THIS IS (1 line)

A mixing desk for a local AI's personality. Each dial is a trained direction inside the model (a "control vector"); the slider is how hard you lean on it. Everything runs on this machine — nothing is uploaded.

THE FULL FLOW, START TO FINISH

  1. 01 MODEL — pick a model file and press LOAD MAIN. Status bar turns ENGINE UP. Takes ~5–10 s and ~1.5 GB RAM for the 0.6B.
  2. 02 DIALS — every dial is a behaviour (poetic, scientific...). Move its slider away from 0 (e.g. +1). Negative pulls in the opposite direction. Press APPLY DIALS — the engine restarts with your settings (~10 s).
  3. SEND → — type one question. It is asked to BOTH engines: A = plain (no dials) and B = steered (your dials at your strengths). Timings show under each answer.
  4. 03 PRESETS — name your dial mix and SAVE. APPLY loads the exact same settings later, so the behaviour is reproducible.
  5. 04 TRAIN A NEW DIAL — want a behaviour nobody made yet? Fill positive ("a hardcore detective...") and negative ("...opposite") personas, press QUEUE. Training is free, local, ~7 min/dial. New dial appears in 02.
  6. ATLAS tab — all experiments, sweeps, sweet spots, failures and every chat you run (auto-logged).

WHAT STRENGTH MEANS

0 = untouched · ~1 = the dial's sweet spot (see ATLAS per dial) · 2 = visible degradation begins · ≥3 = nonsense. Negative direction steers away from theBehaviour. Try extremes deliberately to learn where each dial breaks.

HONEST LIMITS

• pushing too hard breaks the model (that's the point of the danger zone)
• two same-family dials mixed at high strength blur each other — prefer ≤2 dials, ≤1.0
• the model is tiny (0.6B): expect goofy answers; the 1.7B is sharper
• CPU generation ≈ 5–30 tok/s depending on model

IF SOMETHING BREAKS

  • ENGINE DOWN + weird errors → press STOP ALL then LOAD MAIN again.
  • "RAM guard" message → too much loaded at once; stop before loading bigger models.
  • engine crash details live in server/engine_*.log; training logs in scripts/train_*.log.
  • Browser stale page → refresh (Ctrl+R). Server keeps running.
